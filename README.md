# LJT-Homepage

Personal homepage of **Junteng Liu**, first-year PhD candidate at the HKUST NLP Group, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Site contents

- **About** (front page, `_pages/about.md`): personal details, research interests, education, research experience, publications, skills, honors and awards, and contact information.
- **Publications** (`_publications/`, listed at `/publications/`): one Markdown file per paper.
- **CV** (`_pages/cv.md`, listed at `/cv/`): education, research experience, skills, publications, and honors.

## Configuration

- `_config.yml`: site-wide settings and the author/sidebar profile.
- `_data/authors.yml`: author details.
- `_data/navigation.yml`: header navigation.
